# Rust Scout
Rust Scout is a tool for running automated tests on Rust code.

## Usage
1. Create a new instance of the `RustScout` class, passing in the code coverage and e2e tests.
2. Run the unit tests using the `run_unit_tests` method.
3. Run the e2e tests using the `run_e2e_tests` method.
4. Check the code coverage using the `check_code_coverage` method.
5. Check the e2e tests using the `check_e2e_tests` method.
6. Run all tests using the `run_all_tests` method.
7. Check if all tests passed using the `check_all_tests_passed` method.
